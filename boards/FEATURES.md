# Features per board

Generated by `mazduino-tuner/tools/gen_board_features.sh` from what each board sets in `board.mk`, `efifeatures.h` and `prepend.txt`. Do not edit by hand.

This table describes the firmware: a feature marked `-` is not built or not offered on that board. It says nothing about wiring, which is in each board's manual.

On Core the second CAN channel also needs its jumper set, and knock is in the firmware but the 48-pin carrier connector does not bring it out.

Software knock is off by default on every board that has it. Turn it on in the tune.

## BIGFUEL variants

Same hardware and features as the board they are named after, except:

| | Base board | BIGFUEL |
|---|---|---|
| VE table | 16x16 | 32x32 |
| Ignition table | 16x16 | 32x32 |
| Engine sniffer | yes | - |

Tunes are not interchangeable between a board and its BIGFUEL variant.

Boards with a BIGFUEL variant: compact, core, lite, mini6ch.
